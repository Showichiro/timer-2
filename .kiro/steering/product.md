# Product Overview

タイマーアプリケーション - Webブラウザで動作するシンプルなタイマーツール

## Core Capabilities

- **時間管理**: タイマー機能によるカウントダウン/カウントアップ
- **直感的UI**: シンプルで使いやすいインターフェース
- **レスポンシブ対応**: デスクトップ・モバイル両対応

## Target Use Cases

- 作業時間の管理（ポモドーロテクニック等）
- 簡易的なストップウォッチ機能
- イベントや料理などのタイマー用途

## Value Proposition

- ブラウザのみで動作（インストール不要）
- 軽量で高速な起動
- モダンなUIと優れたユーザー体験
